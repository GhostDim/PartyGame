Проект интерактивной настольной игры для Raspberry Pi Zero 2 W.

## Запуск

Нужен Node.js LTS 18 или новее.

На плате с адресной лентой один раз включается SPI. Распиновка, питание и порядок 16 светодиодов — в `docs/PINS.md`. Лента: WS2812B, 4 вертикальные полосы по 4 диода, данные на GPIO 10 (физический пин 19).

```bash
sudo apt update && sudo apt install -y python3-spidev
```

В конец `/boot/firmware/config.txt` (на старом образе тот же файл — `/boot/config.txt`):

```
dtparam=spi=on
core_freq=250
core_freq_min=250
force_turbo=1
```

Эти три строки фиксируют частоту ядра. Без них такт SPI плавает вместе с нагрузкой, длина бита ленты меняется, и диоды вспыхивают на полную яркость. На этой плате лента заработала только после `core_freq`, `core_freq_min` и `force_turbo=1` вместе. После правки файла нужна перезагрузка.

Группа `spi` нужна пользователю, который запускает сервер. На этой плате это `gost`.

```bash
sudo usermod -aG spi gost
sudo reboot
```

После перезагрузки зайдите по SSH заново и проверьте, что устройство на месте:

```bash
ls /dev/spidev0.0
```

Дальше в каталоге проекта:

```bash
npm install
npm start
```

То же самое: `node server.js`. Отдельный процесс для ленты не нужен: сервер сам запускает драйвер.

Сервер слушает порт 3000 на всех интерфейсах.

- Игрок: http://localhost:3000/
- Экран ТВ: http://localhost:3000/tv
- Ведущий: http://localhost:3000/admin — пароль, затем ник и аватар. В комнате это обычный игрок; пульт (старт, кик, режим ТВ) открывается кнопкой в любой момент.

В лобби по каждой из четырёх полос плывёт градиент от белого к жёлтому. После «Начать игру» тот же ход, от жёлтого к красному. Выключатель и яркость (5–100%) лежат в настройках ведущего, кнопка с шестерёнкой. Яркость — это масштаб цвета диодов, отдельного входа у ленты нет. Значение пишется в `data/lights.json` и сохраняется между запусками. По умолчанию лента включена на 5%.

Если SPI недоступен, в лог попадает строка «Подсветка выключена», а экраны игры открываются как обычно. В настройках ведущего при этом видна подсказка, что лента не на линии.

Сигнал ленты идёт через 74AHCT125: пин платы 3,3 В, лента питается от 5,15 В. Полная схема — в `docs/PINS.md`. Выключение платы не снимает питание с бустера: погасшая лента остаётся тёмной, только если перед этим сервер успел записать чёрный кадр.

Пароль ведущего задаётся константой `ADMIN_PASSWORD` в `server.js` (сейчас `admin`). После входа в браузере сохраняется сессионный токен, не пароль.

Клиент Socket.io отдаёт сам сервер с `/socket.io/socket.io.js`. Внешние CDN не используются.

На плате откройте те же адреса по имени хоста, например `http://PartyBox.local:3000/`.

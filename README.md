Проект интерактивной настольной игры для Raspberry Pi Zero 2 W.

Каталог на плате: `~/PartyBox`, пользователь `gost`. Провода и уровни сигналов — в `docs/PINS.md`. Команды ниже выполняются на плате по SSH, кроме копирования файлов.

## Установка

### 1. Сервер Node.js

Ставит Node.js и npm. Нужна версия Node 18 или новее.

```bash
sudo apt update && sudo apt install -y nodejs npm
node -v && npm -v
mkdir -p ~/PartyBox
```

С компьютера, из каталога проекта, копирует файлы на плату:

```bash
scp -r * gost@PartyBox.local:~/PartyBox/
```

На плате ставит библиотеки сервера. Интернет нужен только для этой команды, сама игра потом работает без него.

```bash
cd ~/PartyBox
npm install
```

### 2. Усилитель и динамик

Микросхема MAX98357A, шина I2S. Динамик 4 или 8 Ом подключается только к клеммам усилителя. Вывод GAIN не подключать: так усиление 9 дБ. LRC — это физический пин 35. Физический пин 19 занят лентой.

| Усилитель | Пин платы |
| --- | --- |
| VIN | 4 (5 В) |
| GND | 14 |
| BCLK | 12 |
| LRC | 35 |
| DIN | 40 |
| SD | 7 |

`alsa-utils` даёт команду `aplay`. Группа `audio` открывает пользователю звуковую карту.

```bash
sudo apt install -y alsa-utils
sudo usermod -aG audio gost
sudo nano /boot/firmware/config.txt
```

На старом образе тот же файл лежит в `/boot/config.txt`. Если в файле есть строка `dtparam=audio=on`, поставьте в начале `#`: она занимает GPIO 18, а этот пин нужен усилителю. В конец файла, внутрь секции `[all]`:

```
dtoverlay=max98357a,sdmode-pin=4
```

Без этой строки карты `MAX98357A` нет, и `aplay` отвечает `No such device`. Строка начинает работать после перезагрузки из шага 4.

### 3. Кнопка питания и лента

Кнопка включения и выключения — пины 5 и 6. Данные ленты — пин 19, сигнал идёт через 74AHCT125. Питание ленты с бустера 5,15 В, не с пинов платы. Лента: 48 диодов, 4 полосы по 12. Полосы 1 и 3 перевёрнуты.

`python3-spidev` — доступ к шине SPI из драйвера ленты. Группа `spi` нужна пользователю, который запускает сервер.

```bash
sudo apt install -y python3-spidev
sudo usermod -aG spi gost
sudo nano /boot/firmware/config.txt
```

В конец файла, в ту же секцию `[all]`:

```
dtoverlay=gpio-shutdown,gpio_pin=3
dtparam=spi=on
core_freq=250
core_freq_min=250
```

`gpio-shutdown` включает кнопку на пинах 5 и 6. `dtparam=spi=on` включает шину для пина 19. Две строки `core_freq` держат такт SPI и I2S ровным, иначе диоды вспыхивают на полную яркость. `force_turbo=1` не добавлять: при 5,10 В на бустере плата с этой строкой не включается. Если после правки плата молчит, карту открывают на компьютере и в корне загрузочного раздела удаляют из `config.txt` строки `force_turbo`, `core_freq` и `core_freq_min`.

### 4. Перезагрузка и проверка

Группы `audio` и `spi` и правки `config.txt` применяются после перезагрузки.

```bash
sudo reboot
```

Снова зайдите по SSH:

```bash
ls /dev/spidev0.0
aplay -l
cd ~/PartyBox
aplay -D plughw:CARD=MAX98357A,DEV=0 sounds/startup.wav
npm start
```

`ls` проверяет, что шина ленты на месте. В `aplay -l` должна быть карта `MAX98357A`. Следующая команда играет `sounds/startup.wav`: PCM, 16 бит, моно, 44100 Гц. Чип не принимает 22050 Гц. Свой файл кладут под тем же именем. `npm start` — это `node server.js`: сервер на порту 3000, лента и снова этот звук. Отдельный процесс для ленты не нужен.

## Запуск

После установки сервер из `~/PartyBox`:

```bash
npm start
```

- Игрок: http://PartyBox.local:3000/
- Экран ТВ: http://PartyBox.local:3000/tv
- Ведущий: http://PartyBox.local:3000/admin — пароль, затем ник и аватар. В комнате это обычный игрок; пульт открывается кнопкой в любой момент.

Пароль ведущего — константа `ADMIN_PASSWORD` в `server.js` (сейчас `admin`). В браузере после входа хранится сессионный токен, не пароль.

В лобби по каждой из четырёх полос плывёт градиент от белого к жёлтому. После «Начать игру» тот же ход, от жёлтого к красному. Выключатель и яркость (5–100%) — в настройках ведущего, кнопка с шестерёнкой. Значение пишется в `data/lights.json`. По умолчанию лента включена на 5%.

Если SPI недоступен, в лог пишется «Подсветка выключена», экраны при этом открываются. Если нет звуковой карты, в лог пишется «Звук выключен». Пока сервер не в автозапуске, мелодия играет при запуске `node server.js`, а не в момент подачи питания.

Выключение платы не снимает 5 В с бустера. Лента гаснет, только если сервер успел записать чёрный кадр. Клиент Socket.io отдаёт сам сервер, внешние CDN не используются.
